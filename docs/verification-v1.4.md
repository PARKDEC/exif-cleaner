## 실제 휴지통 연계

사용자 지정 `%USERPROFILE%/.codex/Move-ToRecycleBin.ps1`을 사용해 합성 테스트의 기존 결과 파일 하나를 휴지통으로 이동했다. 실제 경로는 작업 전 채팅에 표시했다.

대상: `%USERPROFILE%/Documents/Codex/2026-11-23/c-users-jihoon2-documents-codex-2026/work/overwrite-integration/output/ex_original.png`의 이전 버전.

기존 결과는 휴지통으로 이동되어 복구 가능하며, 새 결과는 같은 이름으로 저장됐다. 원본 해시는 유지됐고 새 결과의 프롬프트 필드가 제거됐다. 첫 시도는 부모 PowerShell Core의 모듈 경로가 Windows PowerShell에 전달되어 기본 명령을 찾지 못해 파일 이동 전에 중지됐다. 자식 프로세스의 모듈 경로를 시스템 경로로 분리한 뒤 성공했다. 실행 정책이나 영구 환경 설정은 바꾸지 않았다.

단위 테스트의 재활용 대역은 기존 파일을 테스트 백업 위치로 이동하는 방식으로만 동작한다. 그 테스트에서는 실제 파일 삭제를 수행하지 않았다.
