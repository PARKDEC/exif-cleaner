# v1.2.0 검증 기록

검증일: 2026-11-23. 코드 커밋: `e1917ef`.

- 전체 테스트 **36 passed**, 생략·비활성화한 테스트 없음.
- 지정한 저장 폴더에 바로 저장, 기본 위치 복원, 원본과 동일한 위치 거부 확인.
- 한글·공백 경로의 폴더 선택·드롭 입력 모두 지정 저장 위치 사용 확인.
- 기존 결과 파일과 보고서를 덮어쓰지 않는 동작 확인.
- 중복 사전 검사에서 정확한 원본·결과 경로를 반환하고 파일을 쓰지 않는지 확인.
- 확인 모달에 겹치는 결과 파일명이 나타나고 실제 기존 이미지·원본 이미지의 두 썸네일이 표시되는지 확인. `ImageTk.getimage()`로 서로 다른 두 이미지의 픽셀도 비교함.
- 모달 취소 시 작업 스레드를 시작하지 않고 결과 파일·보고서를 만들지 않는지 확인.
- 승인한 중복은 실패 대신 건너뜀으로 집계하고 나머지 이미지가 처리되는지 확인.
- 저장 위치를 무시하는 변이와 모달 승인 조건을 뒤집는 변이를 각각 관련 테스트가 탐지함. 원본 코드 바이트 복구 및 깨끗한 작업 트리 확인.
- Windows onedir 빌드 성공. 썸네일 표시용 `_imagingtk` 바이너리 포함 확인.
- 배포 폴더의 `PromptCleaner.exe`가 실제 실행되어 창을 연 프로세스 확인.

화면 테스트 중 개발용 전역 Tk의 `menu.tcl`을 일시적으로 읽지 못하는 오류가 1회 발생했다. 해당 파일 존재를 확인했고, 실패한 테스트를 단독 실행했을 때 통과했다. 전체 테스트와 빌드는 기존 배포 앱에 포함된 Tcl/Tk 경로를 명시한 환경에서 수행했다. 전역 Python 설치는 변경하지 않았다.

프롬프트 제거 엔진은 v1.0의 검증된 구현을 유지한다. 이전 공식 추출기 검증은 `verification.md`에 기록되어 있다. 이번 변경의 드롭 입력은 콜백을 통한 실제 파일 처리로 검증했으며, 탐색기에서 앱으로 마우스를 옮기는 동작은 자동화 도구의 창 경계 제약으로 최종 검증하지 않았다.
