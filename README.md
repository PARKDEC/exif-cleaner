# Exif Cleaner

이미지를 공유하기 전에 NovelAI 프롬프트와 관련 생성 정보를 제거한 사본을 만드는 Windows 앱입니다. 이미지 업로드·계정·API 키가 필요하지 않습니다.

## 다운로드

[최신 Windows 실행 파일](https://github.com/PARKDEC/exif-cleaner/releases/latest)에서 ZIP을 받아 전체 압축을 풀고 `ExifCleaner.exe`를 실행하세요.

이름의 EXIF 외에도 PNG 텍스트, XMP, IPTC와 지원하는 숨김 생성 정보를 함께 제거합니다.

## 사용법

1. 배포 폴더의 `ExifCleaner.exe`를 더블클릭합니다.
2. 원하는 위치에 저장하려면 먼저 **저장 폴더 선택**을 누릅니다. 선택한 폴더에 사본과 보고서를 바로 저장합니다.
3. **파일 추가**로 PNG·JPG 이미지를 고르거나 **폴더 추가**로 폴더를 고릅니다. 파일·폴더 여러 개를 드롭 구역에 함께 놓아도 됩니다.
4. 처리 중에도 파일·폴더를 추가할 수 있습니다. 추가한 순서대로 대기열에 등록되고, 현재 작업이 끝나면 다음 작업을 자동 처리합니다.
5. 자동 처리가 끝나면 **결과 폴더 열기**를 누릅니다.

직접 지정한 저장 폴더에 `ex_원래이름.확장자` 사본이 저장됩니다. 저장 폴더 지정은 앱을 닫을 때까지 유지되며, 처리 중에는 변경할 수 없습니다. 원본 폴더와 같은 위치는 선택할 수 없습니다. 각 작업은 대기열에 추가될 당시의 저장 위치를 사용합니다. 대기열을 일시중지한 상태에서 저장 위치를 바꾸더라도 이미 등록된 작업의 위치는 바뀌지 않습니다.

같은 이름의 결과 파일이 있으면 해당 작업이 시작되기 전에 확인 모달이 열립니다. 앞선 대기열 작업에서 방금 만들어진 파일도 이때 확인합니다. 겹치는 파일 목록에서 항목을 선택하면 **기존 결과 이미지와 이번 원본의 썸네일**, 기존 파일의 전체 경로와 저장 예정 경로를 볼 수 있습니다.

파일마다 다음 중 하나를 선택한 뒤 **선택 적용**을 누릅니다. 모든 중복 파일에 선택을 정해야 적용할 수 있습니다.

- **덮어쓰기:** 새 사본의 이미지·저장 검증을 마친 뒤 기존 결과를 휴지통으로 보내고 새 사본을 같은 이름에 저장합니다. 기존 결과는 휴지통에서 복구할 수 있습니다. 원본 이미지는 수정하지 않습니다.
- **다른 이름으로 저장:** 같은 결과 폴더에서 사용할 새 이름을 입력합니다. 겹치지 않는 이름을 제안하며, 확장자를 생략하면 원본 확장자를 붙입니다. 다른 경로나 형식으로 바꾸는 이름은 받지 않습니다.
- **건너뛰기:** 이 파일은 처리하지 않고 중복 제외로 집계합니다.
- **취소:** 현재 작업 전체를 시작하지 않고 남은 대기열을 일시중지합니다. 모달에서 정한 선택도 적용되지 않습니다.

확인 이후 기존 결과가 바뀌면 덮어쓰지 않습니다. 휴지통 이동이 실패하면 해당 작업을 중지하고 대기열도 일시중지합니다. 영구 삭제로 전환하지 않습니다. 휴지통 덮어쓰기는 이 PC의 `%USERPROFILE%\.codex\Move-ToRecycleBin.ps1`과 Windows PowerShell을 사용하며, 로컬 고정 드라이브에서만 지원합니다. 도구가 없거나 다른 환경에서는 다른 이름으로 저장·건너뛰기를 사용할 수 있습니다.

손상되었거나 지원하지 않는 파일은 썸네일 대신 미리보기 불가 안내를 표시합니다. 처리 보고서에는 실제 저장 경로와 기존 결과의 휴지통 이동 내역도 남습니다.

기존 보고서는 보존하고 새 보고서에 번호를 붙입니다.

저장 폴더를 따로 선택하지 않거나 **기본 위치**를 누르면, 폴더 작업은 그 폴더 안에, 개별 파일 작업은 그 파일이 있는 폴더 안에 `prompt_cleaned_날짜_시간` 결과 폴더를 매번 새로 만듭니다. 개별 파일을 추가하면 같은 폴더의 다른 파일은 처리하지 않습니다. 폴더의 하위 폴더는 처리하지 않습니다. `.png`, `.jpg`, `.jpeg`를 지원합니다. 파일명이 한글·공백·중괄호를 포함해도 처리할 수 있습니다.

결과 표를 더블클릭하면 처리 내용을 볼 수 있습니다. 표에는 여러 작업의 내역이 누적됩니다. `처리결과.csv`에도 작업별 결과가 남으며 프롬프트 내용은 기록하지 않습니다.

**현재 작업 중지**는 지금 처리하는 파일을 안전하게 마친 뒤 현재 작업의 나머지를 중지합니다. 대기 중인 작업들은 그대로 유지됩니다. **대기열 계속**을 누르면 남은 작업부터 이어서 처리합니다. 중지된 폴더 작업의 미처리 파일까지 다시 처리하려면 해당 폴더를 다시 추가해 주세요.

**대기열 비우기**는 아직 시작하지 않은 작업만 취소하며, 현재 처리 중인 작업과 디스크 파일에는 영향을 주지 않습니다. 대기열은 앱을 켜 둔 동안만 유지됩니다. 앱을 닫으면 현재 파일을 안전하게 마친 뒤 종료하고 대기 중인 작업들은 실행하지 않습니다.

배포 폴더의 `_internal`은 실행에 필요한 파일입니다. `ExifCleaner.exe`와 함께 같은 폴더에 보관해 주세요. Python을 따로 설치할 필요는 없습니다.

## 처리 범위

- PNG의 `Description`, `Comment`, `parameters`, `prompt`, `workflow` 등 알려진 생성 정보 필드와 EXIF/XMP
- JPEG의 EXIF/XMP, IPTC, 주석 세그먼트
- `stealth_pngcomp`, `stealth_pnginfo`, `stealth_rgbcomp`, `stealth_rgbinfo` 숨김 정보
- 알려진 데이터 외의 PNG 작성자 등 텍스트, ICC 색상 프로필, 감마와 DPI 등 표시 정보는 보존

JPEG는 재압축하지 않습니다. 숨김 정보가 없는 PNG도 이미지 데이터를 그대로 유지합니다. 숨김 정보가 있는 PNG는 데이터가 담긴 채널의 최하위 비트를 바꾸고 무손실 재압축합니다. 형식과 크기는 유지하며 변경된 채널 값의 차이는 최대 1/255입니다. 파일 용량은 달라질 수 있습니다.

이 앱은 알려진 저장 방식의 생성 정보 노출을 줄입니다. 파일명 자체에 프롬프트를 적었다면 파일명을 바꿔 주세요. 이미지 복사·재업로드·시각적 추론·알려지지 않은 숨김 방식까지 차단하지는 않습니다. 실제 사용 중인 이미지 한 장으로 NAI Inspect에서 결과를 확인하는 것을 권장합니다.

애니메이션 PNG, 다중 이미지 JPEG, EXIF 회전이 필요한 사진, 256MB·5천만 픽셀 초과 파일, 손상된 파일은 실패 사유를 표시합니다. `_processing`은 작업용 폴더로, 쓰기 실패 때 남은 파일을 공유하지 마세요.

## 개발

Python 3.14에서 개발·검증했습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe build.py --destination dist --work-root work
```

빌드 스크립트는 기존 `ExifCleaner` 배포 폴더를 덮어쓰지 않습니다. 새 목적지를 지정해 주세요. 테스트 자료도 자동 삭제하지 않고 `work/test-artifacts`에 보관합니다.

설계와 요구 사항은 `docs/intent.md`, `docs/architecture.md`에 있습니다.
