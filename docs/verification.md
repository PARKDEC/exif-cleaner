# 검증 기록

검증일: 2026-11-23. Windows 11, Python 3.14.6, Pillow 13.0.0, tkinterdnd2 0.7.0.

## 자동 테스트

- 전체 테스트: **25 passed**. 생략·비활성화한 테스트 없음.
- PNG 일반 생성 정보, 압축 텍스트, iTXt/XMP, EXIF와 IDAT 뒤 메타데이터 제거
- 관련 없는 PNG 작성자 정보·DPI·픽셀, 색상 모드와 16비트 이미지 보존
- alpha/RGB × 압축/비압축의 네 가지 숨김 형식: 식별자뿐 아니라 전체 페이로드 덮어쓰기 확인
- JPEG 픽셀·양자화 테이블·ICC 보존과 주석·EXIF 제거
- 원본 변경 방지, 덮어쓰기 방지, 손상·애니메이션 입력 실패 처리
- 비재귀 폴더 처리, 개별 오류 지속, 중지, 고유 결과 폴더와 CSV
- 한글·공백·중괄호 경로의 드롭 콜백과 폴더 선택 흐름
- 현재 고배율 환경에서 폴더 선택 버튼이 실제로 표시되는지 확인
- RGB 숨김 데이터 제거가 색상 키 투명도를 깨뜨릴 때 저장 거부

## 독립 검증

NovelAI 공식 `nai_meta.py`를 별도 환경에서 사용했다. 합성한 alpha-stealth PNG의
원본에서는 프롬프트를 추출했고, 처리 사본에서는 추출하지 못했다.
같은 검증을 **배포 EXE로 처리한 사본**에도 수행하여 통과했다.

PNG 생성 정보 제거 조건을 의도적으로 무력화한 뒤 관련 테스트가 실패하는 것을
확인했으며, 원래 코드를 복구했다. 코드 검토에서는 투명도 변화 예외를 발견하여
회귀 테스트와 검증을 추가했다. 최종 동작 코드 커밋: `cfe22ee`.

## 배포 EXE 실사용 확인

- Python을 포함한 Windows onedir 빌드 성공
- 결과물 폴더의 실제 `ExifCleaner.exe`를 실행하고 화면 확인
- 실제 폴더 선택 대화상자에서 테스트 폴더를 지정
- 일반 프롬프트 PNG와 숨김 프롬프트 PNG **2개 성공 / 0개 실패** 확인
- 최종 사본·CSV 생성, 원본 해시와 사본의 공식 추출기 검증 통과

탐색기에서 앱으로 마우스를 이동하는 실제 드래그 동작은 자동화 도구가 창 경계 밖
좌표를 허용하지 않아 끝까지 자동 검증하지 못했다. 네이티브 TkDND 로딩·드롭 구역
등록·Tcl 경로 해석·드롭 콜백을 통한 실제 파일 처리는 테스트했다.
NAI Inspect 웹 페이지 자체에 이미지를 올리는 검증은 수행하지 않았다.
사용자 이미지 대신 합성 테스트 이미지만 사용했다.
